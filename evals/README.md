# 评测集

用来回答一个问题：装了 HelloAGENTS 之后，模型的产出是否变好了？每一次想给内核或技能加内容，先用它验证“加了确实更好”；答不出就不加。

## 方法

对每个任务做对照运行：同一宿主、同一模型，分别在「未安装」与「安装 4.0」两种环境执行相同的任务提示词，人工比较结果并记录以下指标：

- 完成质量：结果是否正确、是否达到任务里写明的验收标准（1~5 分）。
- 变更规模：diff 行数、新增文件数——过度工程探针类任务里，这两个数字越小越好。
- 验证行为：模型是否自发运行了项目的验证命令并展示输出。
- 交付表达：是否直接、无套话、无邀约式收尾。

## 运行方式

1. 为任务准备一个干净的示例项目（tasks/ 里各任务写明了要求）。
2. 在宿主中粘贴任务提示词，完整跑完，保存会话记录与最终 diff。
3. 换另一种环境重复一次，把两组指标记入 results.md（自建）。

任务定义在 tasks/ 目录，其中标注「探针」的任务专门检验反过度工程条款是否生效。
